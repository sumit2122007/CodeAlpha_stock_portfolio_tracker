# Stock Portfolio Tracker

A simple Python command-line application built as **Task** for the **CodeAlpha Python Programming Internship**.

## Features
- Predefined stock price dictionary (`AAPL`, `TSLA`, `GOOGL`, `MSFT`, `AMZN`, `RELIANCE`, `TCS`).
- Interactive user input with validation for stock symbols and share quantities.
- Calculates individual stock valuation and total portfolio investment.
- Exports portfolio summaries in both a formatted `.txt` table and `.csv` file.

## How to Run
```bash
python stock_tracker.py
